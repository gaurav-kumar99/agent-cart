# 🛍️ AgentCart

AgentCart is an AI-powered smart shopping and checkout assistant that allows users to converse with an AI agent, instantly build optimized carts from a rich multi-category product catalog, manage items with budget tracking, and seamlessly complete transactions using PayPal Sandbox or instant test simulation.

Built for the hackathon by **Gaurav Kumar** in India 🇮🇳.

---

## ✨ Features
* **🤖 Gemini AI Integration:** Natural language prompt processing to intelligently build custom bundles based on user requests.
* **📂 Categorized 150+ Product Catalog:** Organized sections (Gaming, Coffee, Outdoor, Fitness, Office, Tech, Kitchen) with clean "Show More/Less" toggles and live keyword filtering.
* **🛒 Smart Cart Management:** Real-time item adding/removing, dynamic total calculations, and a visual **Budget Limit Progress Bar**.
* **💳 Dual Checkout Options:** 
  * Official **PayPal Smart Buttons SDK** integration for Sandbox test payments.
  * Instant **Test Payment Simulation** mode for lightning-fast demo recordings.
* **👤 User Profile & Order History:** Persistent storage using `localStorage` to review past transaction receipts.

---

## 🚀 Quick Start
Because this is built as a lightweight, high-performance single-file web application, you don't need complex terminal setups or heavy backend servers to run it!

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
3. Start shopping or chatting with the AI assistant!

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Styling with Slate Grey, Burgundy, Golden, and Marigold palette), Vanilla JavaScript (ES6+).
* **AI:** Google Gemini API.
* **Payments:** PayPal JavaScript SDK.
